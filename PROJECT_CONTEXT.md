# Project Goal

Develop a fully open-source programmer for the CH32V003 using an ESP32-S3.

Hardware:

ESP32-S3:
- YD-ESP32-S3 N8R2

Target:
- CH32V003A4M6 SOP16

Development:
- Arduino IDE
- Windows 11

Goals:

1. GPIO Timing
2. Open Drain
3. SWIO
4. Read Chip ID
5. Flash Erase
6. Flash Program
7. Flash Verify
